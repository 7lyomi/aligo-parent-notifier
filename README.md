# 학부모 알림톡 업무 자동화

**엑셀에 입력한 학생별 학습 기록을 메시지로 만들고, 미리보기·수정을 거쳐 일괄 발송하는 Windows 로컬 웹 도구입니다.**

[![Tests](https://github.com/7lyomi/aligo-parent-notifier/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/7lyomi/aligo-parent-notifier/actions/workflows/tests.yml)

| 적용 현장 | 비용 개선 | 사용자 피드백 반영 |
|---|---|---|
| **300명 규모 학원**의 학부모 안내 업무 | 월 **233,100원 → 58,500원**, 약 **74.9% 절감** | 단어 시험만 있는 날·주간·월간의 **3종 안내** |

비용은 프로젝트 당시 단가(장문 문자 25.9원, 알림톡 6.5원)에 같은 월 발송량 **9,000건(300건 × 30일)**을 적용한 비교입니다. 월 절감액은 **174,600원**입니다. 300명은 안내 대상 규모이며, 업무 시간 절감률은 따로 측정하지 않았습니다.

## 데모 실행

Python **3.10 이상**이 필요합니다. Windows 설치 시 `Add python.exe to PATH`를 선택합니다.

1. **Code → Download ZIP**으로 내려받아 완전히 압축 해제합니다.
2. `install_windows.bat`를 실행합니다. 최초 설치에는 인터넷 연결이 필요합니다.
3. `start_demo.bat`를 실행합니다.
4. 브라우저의 `http://127.0.0.1:5050`에서 **가상 샘플 불러오기**를 누릅니다.

가상 학생 12명으로 미리보기·수정·선택/전체 시뮬레이션을 확인할 수 있습니다. **기본 데모는 외부 API를 호출하지 않아 발송 비용이 발생하지 않습니다.**

macOS·Linux에서는 가상환경을 만든 뒤 `python -m pip install -r requirements.txt`, `python app.py`로 실행할 수 있습니다. 실제 발송 설정과 기존 데이터 이관은 [실행 및 운영 안내](docs/usage.md)를 참고합니다.

## 왜 만들었나요?

원장님이 매일 학생마다 다른 메시지를 복사해 학부모에게 보내는 데 많은 시간과 수고가 든다고 문의했습니다. 학습 기록을 입력하면 메시지를 생성해 일괄 발송하는 기능을 제안하고, 요청한 양식으로 문자 버전을 구현했습니다.

그런데 안내가 장문 문자로 처리돼 비용 부담이 커졌습니다. 대안을 조사해 카카오 비즈니스 승인 템플릿을 등록하고 알리고 알림톡 API로 전환했습니다. 이후 **단어 시험만 있는 날·주간 테스트·월간 테스트**라는 추가 요구를 반영해 최종 운영본을 전달했고, 현재 편리하게 잘 사용하고 있다는 후기를 받았습니다.

요구사항 파악, 업무 흐름 설계, 발송 방식 선택, 승인 템플릿 준비, 피드백 반영과 운영 확인을 수행했습니다. 공개 준비 과정의 코드 개선·리팩터링과 회귀 검사에는 AI 코딩 도구를 활용했습니다. [개발 과정과 선택의 근거](docs/development.md)

## 주요 기능

| 기능 | 동작 |
|---|---|
| 엑셀 → 개인별 메시지 | 학생DB와 데일리 리포트를 학생ID로 연결하고 이름도 교차 확인합니다. |
| 3종 안내 | 없음·주간·월간에 따라 승인 템플릿과 변수를 선택합니다. `없음`은 주간·월간 테스트가 없다는 뜻이며 단어 시험은 공통입니다. |
| 미리보기·검수 | 생성된 내용을 수정·저장·확인한 뒤 선택 또는 전체 발송합니다. |
| 입력 검증 | 동명이인·중복 ID·잘못된 날짜·번호·퍼센트·개수·점수를 발송 전에 확인합니다. |
| 중복 요청 방지 | SQLite 예약으로 반복 요청을 막고, 결과가 불확실한 요청은 자동 재시도하지 않습니다. |
| 발송 결과 기록 | CSV로 요청 결과를 남깁니다. API 요청 접수와 실제 수신은 구분합니다. |

## 기술과 구조

**Python · Flask/Jinja2 · openpyxl · requests · SQLite · python-dotenv**

사용자가 Windows PC와 Excel로 업무를 처리하는 환경에 맞춘 로컬 앱입니다. `app.py`는 실행만 담당하고, `notifier/`에서 엑셀 처리·메시지 생성·외부 API·저장·웹 요청을 나눕니다. 앱별 설정과 저장 경로를 주입해 검사 환경의 상태도 분리했습니다. [모듈별 역할과 수정 위치](docs/architecture.md)

## 검사와 운영 기록

```bash
python -m unittest discover -s tests -v
```

30개 회귀 검사는 동명이인, 입력 오류, 중복 예약, API 오류, 300행 처리, 앱별 상태 분리를 확인합니다. 외부 발송 API는 모의 응답으로 대체합니다. GitHub Actions는 PR과 `main` 변경 시 같은 검사를 Python 3.10·3.12에서 실행하며, **위 배지에서 실제 실행 결과를 확인**할 수 있습니다.

운영본의 **Windows 실행과 실제 알림톡 수신은 작성자가 확인**했습니다. 현장 운영 확인과 공개용 코드의 자동 검사 범위는 [검증 기록](docs/verification.md)에 구분했습니다.
