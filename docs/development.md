# 개발 과정과 선택의 근거

## 요구사항에서 운영까지

원장님은 매일 약 300명의 학부모에게 학생별로 다른 내용을 복사해 보내는 일이 번거롭고 시간이 오래 걸린다고 문의했습니다. 학습 기록만 입력하면 학생별 메시지를 만들어 한 번에 발송하는 기능을 제안했습니다.

| 단계 | 발견한 문제·요구 | 판단과 구현 |
|---|---|---|
| 반복 업무 문의 | 매일 학생마다 다른 메시지를 복사·붙여넣기 | 엑셀 입력을 개인별 메시지 생성·일괄 발송으로 연결 |
| 문자 버전 적용 | 원장님이 사용하는 안내 양식 필요 | 요청한 형식에 맞춰 본문을 만들고 외부 발송 API 연동 |
| 비용 문제 발견 | 안내가 장문 문자로 처리돼 건당 25.9원 발생 | 기능 구현 후 실제 운영 단가도 다시 검토 |
| 알림톡 전환 | 건당 6.5원으로 학습 안내 전달 가능 | 카카오 비즈니스 승인 템플릿을 등록하고 알리고 알림톡 API 연동 |
| 추가 피드백 | 단어 시험만 있는 날·주간·월간의 세 경우 | 안내 유형별 승인 템플릿과 변수 분기 구현 |
| 최종본 전달 | 학원의 실제 운영 규칙까지 반영 필요 | 수정본 전달 후 현재 편리하게 사용하고 있다는 후기 확인 |

이 과정은 작성자가 제공한 실제 운영 경험을 바탕으로 정리했습니다. 과거 개발 당시 없었던 Issue나 PR을 소급해 만든 기록은 아닙니다.

## 운영에 맞춘 선택

### Windows 로컬 앱

학원에서 사용하는 PC와 Excel을 중심으로 파일을 읽고 브라우저에서 조작하도록 구성했습니다. 배치 파일로 설치와 실행을 제공하며 별도 서버를 운영할 필요가 없습니다. 단일 운영자의 로컬 업무 도구이며, 여러 사람이 원격으로 접속하는 서비스를 목표로 만들지 않았습니다.

### 발송 전 사람이 검수

학생별 내용이 실제 학부모에게 전달되므로 운영자가 생성된 본문을 읽고 수정할 수 있게 했습니다. 수정 사항을 저장하고 미리보기를 다시 확인한 뒤 발송하는 흐름을 유지합니다.

### 날짜별 안내 유형

`없음`은 주간·월간 테스트가 없는 날을 뜻합니다. 단어 시험은 세 유형 모두에 포함하며, 주간·월간인 경우에만 레벨·점수·평균을 추가합니다.

## 공개 준비 과정의 개선

| 확인한 문제 | 개선 | 이유 |
|---|---|---|
| 이름만으로 학생 연결 | 학생ID 우선 매칭·이름 교차 확인 | 동명이인의 내용과 수신자가 섞이지 않도록 |
| 반복 클릭·재시도 | SQLite 요청 예약과 지속 이력 | 화면 버튼 제어 외에 실제 요청 중복도 막도록 |
| 타임아웃의 결과 불확실 | 확인 대기로 남기고 자동 재시도 차단 | 이미 접수된 요청을 다시 보내지 않도록 |
| Excel 퍼센트 표시와 저장값 차이 | 값과 셀 서식을 함께 해석 | 90%가 0.9%로 전달되지 않도록 |
| 잘못된 입력 | 날짜·번호·수치 범위·유형별 필수 항목 검증 | 발송 전에 오류를 발견하도록 |
| 운영 파일 공유 | 가상 샘플·빈 자격증명 예시·운영 파일 제외 | 실제 학원 및 연락처 정보를 공개본에서 제거 |
| 한 파일에 집중된 코드 | `notifier/` 패키지로 역할 분리 | 엑셀·메시지·API 변경의 수정 위치를 명확히 하도록 |
| 수동 검사에 의존 | 기존 회귀 검사를 GitHub Actions에 연결 | 이후 PR과 main 변경에서 동작을 다시 확인하도록 |

공개용 코드 개선·리팩터링과 회귀 검사에는 AI 코딩 도구를 활용했습니다. 요구사항과 사용 환경의 이해, 비용 전환 판단, 승인 템플릿 준비, 사용자 피드백 반영과 현장 확인을 프로젝트의 주요 경험으로 기록합니다.

## 성과를 해석하는 기준

당시 단가에 같은 월 발송량 9,000건을 적용하면 장문 문자는 233,100원, 알림톡은 58,500원입니다. 월 차액 174,600원을 기존 비용으로 나눈 절감률은 약 74.9%입니다. 단가와 운영 경험은 작성자 제공이며 이 수치는 동일 발송량 조건의 비용 비교입니다.

300명은 학원과 안내 대상의 규모입니다. 프로그램의 동시 사용자 수나 부하 시험 결과를 뜻하지 않습니다. 업무 시간이 줄고 사용이 편해졌다는 피드백은 받았지만 소요 시간을 정량 측정하지 않아 시간 절감률은 제시하지 않습니다.
