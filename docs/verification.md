# v7 수정 및 검증 기록

검증일: 2026-09-10

## 수정 내용

- 학생ID 우선 매칭과 학생명 교차 확인. ID 없는 동명이인, 중복 ID, 같은 학생의 중복 리포트를 차단합니다.
- SQLite에 발송 요청을 먼저 예약합니다. 반복 클릭·반복 요청·재시작 후 동일 요청을 막습니다. 결과를 확인하지 못한 요청도 재전송하지 않습니다.
- 날짜, 휴대전화번호, 퍼센트, 단어 개수, 테스트 구분·레벨·점수·평균을 검증합니다. Excel의 퍼센트 저장값과 표시 서식을 함께 해석합니다.
- 선택·전체 발송 모두 유형별 본인 번호 수신 확인을 요구합니다. 저장하지 않은 수정 내용과 오래된 화면에서는 바로 전송하지 않습니다.
- 실제 학원명, 기존 샘플 개인정보와 운영 파일을 공개본에서 제외했습니다. 설정 예시의 자격증명은 비워두고, 기본 실행은 외부 API를 사용하지 않는 데모입니다.

## 자동화 검사

Linux / Python 환경에서 `python -m unittest discover -s tests -q`를 실행하여 **29개 검사 모두 통과**했습니다. 자동화 검사에서는 외부 API를 모의 응답으로 대체했습니다.

| 범위 | 확인한 동작 |
|---|---|
| 학생 연결 | 같은 이름·다른 ID, ID와 이름 불일치, 중복 ID, ID 없는 기존 파일, 중복 리포트, 발송 제외 |
| 입력 | 숫자와 퍼센트 서식 차이, 허용 범위, 잘못된 날짜·번호, 테스트 구분 누락, 데모 번호의 운영 차단 |
| 웹 요청 | Flask 테스트 클라이언트의 실제 샘플 업로드·미리보기, CSRF, 오래된 화면, 저장 전 발송 보류 |
| 발송 흐름 | 데모의 외부 API 미호출, 선택·전체 발송의 수신 확인, 템플릿 설정 변경 시 확인 무효화, 본인 테스트 번호 사용 |
| 중복·오류 | 접수 후 반복, 타임아웃, 결과 코드 없는 응답, 명시적 거절 후 재시도, 동시 예약, 로그 기록 실패 |
| 행 수 | 300행 처리와 CSV 기록, 500건 초과 요청의 분할 |

300행 검사는 기능 검사이며 성능·부하 시험이나 실제 300명 동시 발송을 재현한 시험은 아닙니다.

## 실제 운영 확인

자동화 검사와 별도로 작성자가 실제 운영 환경에서 다음 내용을 확인했습니다.

- Windows 환경에서 설치·실행 및 브라우저 조작 확인
- 알리고와 카카오 비즈니스 승인 템플릿을 이용한 실제 알림톡 수신 확인
- 테스트 없음·주간 테스트·월간 테스트 3종 운영 흐름 반영
- 300명 규모 학원의 실제 학부모 안내 업무에 적용
- 최종본 전달 후 운영자가 현재 업무에서 편하게 사용하고 있다는 피드백 확인

따라서 이 저장소의 자동화 검사는 네트워크를 모의 처리하지만, **프로젝트 자체의 Windows 실행과 실제 알림톡 발송·수신은 별도의 실제 운영 과정에서 확인된 상태**입니다.

## 비용 개선 확인

기존 장문 문자 단가 25.9원, 알림톡 단가 6.5원, 하루 300명·30일 발송을 기준으로 계산했습니다.

- 기존: `25.9원 × 300명 × 30일 = 233,100원`
- 변경: `6.5원 × 300명 × 30일 = 58,500원`
- 절감액: `174,600원 / 월`
- 절감률: 약 **74.9%(약 75%)**

이는 동일 발송량을 기준으로 한 비용 비교이며 업무 시간 절감률과는 별개의 지표입니다.

## 운영상 주의사항

이 릴리스에는 이전 v6의 발송 이력이 포함되지 않습니다. 중복 방지는 이 프로그램의 로컬 이력이 남아 있는 범위에 적용됩니다. 본문·학생ID·수신번호를 변경하거나 이력을 삭제하면 동일 요청으로 인식하지 않을 수 있습니다. 응답이 불확실한 경우 알리고 발송 내역을 먼저 확인해야 합니다.
